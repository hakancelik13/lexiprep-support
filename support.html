LexiPrep Support

LexiPrep supports vocabulary and grammar learning for GRE, GMAT, SAT, ACT, TOEFL, and general English. Core learning features work offline and do not require an account.

Purchases and refunds

LexiPrep is a one-time paid App Store download. There are no subscriptions or in-app purchases. Apple processes all payments and refunds. For billing questions or to request a refund, visit reportaproblem.apple.com.

Contact support

Email hakancelik13@gmail.com. Please describe the problem, your iPhone model, iOS version, and LexiPrep version. Never include an API key in an email or screenshot.

Personal AI

Personal AI is optional and uses the user's own OpenAI API account. A ChatGPT subscription does not automatically include API credits. To disconnect it, open LexiPrep → Profile → Personal AI → Remove API key.

Microphone problems

Open Settings on your iPhone or iPad, then go to Privacy & Security → Microphone and allow LexiPrep. Microphone access is needed only for optional AI voice-answer checking. The offline synonym checker remains availablewithout microphone access or Personal AI.

Reset learning data

Open LexiPrep → Profile and use the reset option. This permanently clears locally stored progress, custom words, favorites, points, and the saved personal API key.
